# Arjun WhatsApp Bot
WhatsApp Bot which integrates with arjun enabling users to manage their schedule directly on WhatsApp.

## Getting Started
To get started locally.

* Clone this repo locally
* Then create your environment variables.
```
cp .example.env .env
```
```
npm install
```
```
npm run dev
```
* Start developing.

## Abbreviations
WA or wa : WhatsApp
